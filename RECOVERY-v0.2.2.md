# GeoGebraForQuest v0.2.2 startup recovery

This release deliberately restores the launcher, WebView hosting, local GeoGebra boot sequence, and first spatial transition to the proven v0.1.2 implementation.

The v0.2 native stereo portal renderer remains in the source tree but is not activated by this recovery build. First goal: the APK must reliably open ordinary GeoGebra on Quest again.
